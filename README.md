# MindCare AI

MindCare AI is a personal mental health companion designed to provide supportive conversations and helpful guidance. It combines voice and chat interactions to create a safe space for self-reflection.

This project also served as a hands-on way to learn how **OpenRouter** and generative AI models work in real applications. For privacy, the app **only stores login and authentication data**; conversation content is **not stored**.

---

## Features

* **Voice Conversations:** Talk naturally with Vapi AI-powered voice.
* **Text Chat:** Express yourself via OpenRouter-powered chat.
* **Multi-language Support:** Communicate in multiple languages.
* **Privacy First:** Only login data is stored; conversations are never saved.
* **24/7 Availability:** AI support anytime you need it.
* **Advanced AI:** Compassionate and context-aware assistance.

---

## Tech Stack

* **OpenRouter** – Chat LLM responses
* **Vapi AI** – Voice interaction
* **Supabase** – Authentication and user management
* **JavaScript** – Application logic 

---
 

## Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/julikray/MindCare-AI.git
   
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Set up environment variables**

   Create a `.env` file and add your OpenAI API key, Vapi credentials, and Supabase keys.

4. **Run the app**

   ```bash
   npm run dev
   ```
